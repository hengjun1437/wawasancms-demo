# WawasanCMS Cloud — Public Synthetic Demo

This public repository contains **only simulated sample data** and a browser-only dashboard. It does not provide real authentication, customer access, CCTV/NVR connectivity or a production API.

Never add credentials, customer information, backend code or gateway sources here.

Publish with **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

Open the resulting GitHub Pages URL to view Customer A. Add `?demo=b` for Customer B. The public site is accessible to anyone.
